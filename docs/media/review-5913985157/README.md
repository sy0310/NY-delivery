## TapTap 与实体手机测试

按用户确认，以遇亭工作室的开发者身份创建《我在纽约送外卖》模拟类H5测试草稿。TapTap成功接收 `ce62b43` 测试包并生成自测二维码，二维码已在本次对话以PNG交付。包体为真实Creator发布输出，横屏配置，ZIP单一game目录，game/index.html位于第一层。

二维码对应的手机启动、TapTap内WebView能力、文件选择及音频策略仍需设备验证。当前手机入口使用本次对话的TapTap自测二维码。历史LAN记录保留其原始验证范围。

手机短测试单如下，逐项记录设备、系统、TapTap版本、运行容器和画质。

1. 扫码进入，检查横竖屏、安全区、文字和可点击范围。
2. 同时操作摇杆与观察、油门与转向，检查松开、移出和取消后的归零。
3. 系统文件中选两首有权使用的MP3/WAV，检查取消、追加、上下车与下一单连续。
4. 主动暂停音乐后切App、锁屏并返回，试听“恢复声音”与全静音，检查暂停意图。
5. 外部播放器分别按先游戏后音乐、先音乐后回游戏两种顺序操作，记录全静音共存及保留游戏音效的结果。
6. 至少完成一单并持续到15分钟，分别记录活跃、暂停、后台、卡顿、发热及中断。
