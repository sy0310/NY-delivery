# 我在纽约送外卖

## 体验

固定傍晚，在纽约风格街区选择自己的音乐，驾驶送餐。停车、步行进店、排队、等餐、核验交接码、拿袋、装车、送达与结算组成一单。声音、等待和环境动作提供反馈。长期保留汽车与电瓶车两种方式。

## v0.1 范围

一个路口及短道路、一家暖灯餐厅取餐区、一位排队 NPC、店员、餐袋、一个送达门口与带基本内饰的汽车。手机、仪表和交互提示保持可读，速度单位 mph。

完整流程为选歌、接单、驾驶、停稳下车、进店排队、等待厨房、核码、取餐、回车装袋、驾驶送达、步行交付、查看结果并开始下一单。

首单使用虚构餐厅 Juniper Kitchen、虚构顾客 Alex Rivera 和可替换交接码 4826。手机、柜台和餐袋读取同一份订单。

## 模块

| 模块 | 职责 | 后续复用 |
| --- | --- | --- |
| OrderState | 订单、独立队列和备餐计时、核码、一次性结算 | 两种载具共享 |
| VehicleController | 简化汽车加速、刹车、转向与碰撞 | 保留载具接口边界 |
| WalkingController | 前后移动、横移、朝向与障碍检查 | 两种载具共享 |
| TouchControls / TouchInput | 独立摇杆、视角、踏板指针与情境按钮 | 手机触屏与浏览器试用 |
| MusicPlayer | 单播放器、浏览器本地选歌、距离音量与导航压低 | 两种载具共享 |
| DeliveryDemo / World | Cocos 场景、交互距离、手机和仪表 | 扩展餐厅与路线 |
| CarModel / ModelGeometry | 车厢、真实仪表与导航、后视摄像机、复用网格和静态合批 | 扩展载具与街景 |

原型先采用运动学车辆与水平障碍碰撞，重点检查低速转弯和停车。实现与选定物理后端以验证文档为准。

## 里程碑和验收

### v0.1

- 环境诊断须复现原入口，记录失败层级、实际请求与修复或绕行结果。
- Creator 3.8.8 打开正式工程，完成导入、预览、Web Desktop 构建和 HTTP 运行。
- 发布构建连续完成两单，错误核码与重复操作无法越过状态限制。
- 停稳上下车、安全落点、障碍碰撞与恢复入口经过实际操作。
- 演示音乐和本地 MP3/WAV 可选，取消与坏文件有反馈。上下车持续同一播放时间线。
- 三张实机截图与 60—90 秒带游戏声音录屏，记录设备、浏览器、分辨率和性能。
- 干净工作树导入与构建通过，阶段提交推送至同一条 Draft PR。

### v0.2

1. 在 v0.1 实测问题修复后，将车辆控制输入整理成汽车与电瓶车共用的交互约定。
2. 新增电瓶车模型、骑乘镜头、低速平衡和停车，复用既有订单、餐厅与音乐。
3. 加入一段适合连续驾驶听歌的路线，增加第二个取餐入口以验证数据替换。
4. 分别完成汽车和电瓶车送单，回归音乐连续、取餐幂等和安全下车。

### 后续

依据试玩反馈扩展街区、订单变化、天气和目标平台。完整纽约、复杂交通、多人联网、付费系统与多平台发布超出当前范围。
