## 体验

固定傍晚，在纽约风格街区选择自己的音乐，驾驶送餐。停车、步行进店、排队、等餐、核验交接码、拿袋、装车、送达与结算组成一单。声音、等待和环境动作提供反馈。长期保留汽车与电瓶车两种方式。

## 原样片范围与模块历史

两个实际连通的小街区、一家暖灯餐厅、一位短排队骑手、动态店员、共享袋签、三个送达入口与细化驾驶舱。手机、仪表和交互提示保持可读，速度单位 mph。

完整流程为自由选歌或静音接单、驾驶、停稳下车、进店排队、等待厨房、核码、取餐、回车装袋、驾驶送达、步行交付、查看结果并开始下一单。

首单使用虚构餐厅 Juniper Kitchen、虚构顾客 Alex Rivera 和可替换交接码 4826。手机、柜台和餐袋读取同一份订单。

## 模块

| 模块 | 职责 | 后续复用 |
| --- | --- | --- |
| OrderState | 订单、独立队列和备餐计时、核码、一次性结算 | 两种载具共享 |
| VehicleController | 简化汽车加速、刹车、转向与碰撞 | 保留载具接口边界 |
| WalkingController | 前后移动、横移、朝向与障碍检查 | 两种载具共享 |
| TouchControls / TouchInput | 独立摇杆、视角、踏板指针与情境按钮 | 手机触屏与浏览器试用 |
| MusicPlayer / Playlist / MusicPanel | 单播放器、可见本地队列、来源与录屏模式、独立混音 | 两种载具共享 |
| Interaction / CityLayout / OrderTiming | 统一情境动作、连通路网、分阶段实测 | 订单与载具共享 |
| DeliveryDemo / World / Person | Cocos 集成、动态人物、手机与场景 | 扩展餐厅与路线 |
| CarModel / ModelGeometry | 车厢、真实仪表与导航、后视摄像机、复用网格和静态合批 | 扩展载具与街景 |

原型先采用运动学车辆与水平障碍碰撞，重点检查低速转弯和停车。实现与选定物理后端以验证文档为准。
